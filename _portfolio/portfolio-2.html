" collection: portfolio link: /publication/2026-08-01-telecom-quantum-memory-nanophotonic-lithium-niobate --- I work on building high-performing quantum memory for quantum information processing and networking. I've implemented memory schemes on erbium-doped thin-film lithium niobate (Er:TFLN), storing telecom-band single photons for over a microsecond — a record efficiency-storage-time product for any integrated nanophotonic platform, as described in our Nano Letters manuscript below. I'm currently pursuing approaches to push memory efficiency even higher using slow light.
